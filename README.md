# 🏙️ Urban Pulse: City Life Navigator
### *Exploring, Experiencing & Navigating the Chaos We Call Home*

**DYPCOEI Prompt War Hackathon Submission**

---

## 🌟 Executive Summary & Concept
City life is an intricate, exhilarating adventure — balancing the thrill of discovering hidden street food gems and historic landmarks with the chaos of urban congestion, sudden weather shifts, and night safety concerns.

**Urban Pulse** is an intelligent, full-featured city navigation and telemetry platform that transforms scattered urban data, safety heatmaps, and citizen reports into verified, actionable intelligence.

---

## 🚀 Key Feature Pillars

### 1. 🍽️ Exploration & Hospitality
- **Local Gastronomy Radar:** Verified street food icons, historic Irani bakeries, and gourmet cafes.
- **Stay Sanctuaries:** Filterable boutique hotels, safe youth hostels, and budget sanctuaries.
- **Hygiene & Safety Metrics:** Real-time cleanliness and night safety ratings for every listing.

### 2. 🏛️ Living History & Culture
- **Architectural Lore & Heritage Sites:** In-depth historical profiles of ancient fortresses (Shaniwar Wada, Sinhagad), colonial landmarks (Aga Khan Palace, Gateway of India), and palaces.
- **Virtual Audio Walk Engine:** Procedural Web Audio ambient soundscapes with voice-guided transcripts.
- **Local Dialect & Etiquette Guide:** City-specific slang dictionary (*Puneri Patya*, *Chai Katta*, *Bambaiya*, *Macha*).

### 3. 🛡️ Safety, Security & Safe Routing
- **Emergency Rapid Response Console:** One-click instant hotlines (Police 112, Women's Helpline 1091, Ambulance 108, Tourist Support).
- **Hazard Zones & Caution Radar:** Real-time monitoring of reported blind spots, accident-prone turns, and poorly lit corridors with safer detour alternatives.
- **Fake Call Escape Simulator:** Discreet incoming call tool to safely excuse yourself from uncomfortable surroundings.
- **One-Click GPS Broadcast:** Instantly encrypt and copy live coordinates for family dispatch.

### 4. ⚖️ Best vs. Worst Places (Urban Benchmark Matrix)
- **5-Dimensional Comparative Benchmark:** Side-by-side locality comparison across:
  1. *Safety & Night Security*
  2. *Cleanliness & Sanitation*
  3. *Affordability & Cost Index*
  4. *Transit & Walkability*
  5. *Green Canopy & Air Quality (AQI)*
- **Comparative Differential Bars:** Direct percentage deltas (+15% cleaner, -22% more affordable) with tailored persona match recommendations.

### 5. 📊 Smart City Live Telemetry & Citizen Wire
- **Microclimate & Rain Radar:** Real-time temperature, humidity, and microclimate rain alerts.
- **Live Traffic Congestion Index:** Live speed (km/h) monitoring and bottleneck tracking.
- **Citizen Verified Live Wire:** Community hazard reporting with voice note attachments, photo uploads, and crowd-upvoted verification.

### 6. 🤖 Urban AI Copilot (NLP Navigator)
- **Conversational Intelligence:** Generates custom 1-day budget itineraries, night safety audits, and transit bypasses.
- **Instant Prompt Chips:** Pre-configured queries for budget travel, late-night safety, and neighborhood matching.

## 🛠️ Technology Stack
- **Framework:** Next.js 16 (App Router, Turbopack, React 19)
- **Language:** TypeScript
- **Styling:** Vanilla CSS & Tailwind CSS with Glassmorphism Design System
- **Audio Synthesis:** Procedural Web Audio API (6 atmospheric synthesizers)
- **Icons & Visuals:** Lucide React, HTML5 Canvas Visualizers, Canvas Confetti
- **Mapping:** Dynamic Interactive SVG & Mesh Spatial Geolocation

## 💻 Local Installation & Setup

```bash
# Clone the repository
git clone https://github.com/jadhavroshani713-sys/Prompt-war-dypcoei.git

# Navigate to project directory
cd Prompt-war-dypcoei

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
